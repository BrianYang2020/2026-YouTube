## 2. 影片描述（≤300 字）

有消息說 Gemini 的 Gems 要停用，很多人焦慮。我的看法是：它不是要被淘汰，是本來就該升級成 Skill。

Skill 說穿了就是一份寫給 Agent 看的使用說明書，只要是你會重複做的流程，都能變成技能。而且它能做到 Gem 做不到的事。

這一集把三件事一次講完：
・**備份**：免費用戶用 Google Takeout 就能把所有 Gems 的名稱、說明、系統提示詞與附加檔案完整匯出；付費用戶可以直接叫 Spark 幫你打包到雲端硬碟。
・**升級**：我把新版的「Gem 升級成 Skill」提示詞放上 GitHub repo，你只要把網址丟給任何一個 Agent，它就會列出你所有的 Gems，問你要升級哪一個，還會給你能力加值選項。示範把英文偵錯密碼 Gem 升級成會自動生圖、直接輸出互動闖關網頁的 Skill。
・**分享**：把技能放上 GitHub repo 公開，換 Agent、換電腦、分享給別人都是一個網址的事。

最後用 PadletAutoBoard 做示範：一句提示詞，Agent 自動上網找資料、建好整面 Padlet，含參考資料、投票、留言板與備用區段。

## 7. 內容備註（給日後剪同系列參考）

- **核心定義**：Skill ＝ 一份寫給 Agent 看的使用說明書（內容、流程、資源、輸出、觸發情境）。你不用讀懂，Agent 讀得懂。只要是會重複執行的流程，都能變成技能。
- **Gems 停用傳聞**：系統訊息提到 Google 計畫 10 月 20 日停止支援現有 Gems，但尚無正式新聞稿。講者立場：不是淘汰，是升級，Skill 能做的比 Gem 多太多。
- **備份三條路**：
  1. 免費用戶直接問 Gemini「怎麼把 Gems 提示詞備份到雲端硬碟」。
  2. **Google Takeout 官方匯出**：取消全選 → 只勾 Gemini → 多種格式（預設 HTML，AI 讀得到）→ 新增至雲端硬碟 → 僅匯出一次 → Zip → 建立匯出作業。解壓後會有 `Gemini Gems Data` HTML，內含所有 Gems 的名稱、說明、系統提示詞與附加檔案。
  3. 付費用戶叫 **Spark** 直接打包成壓縮檔丟雲端硬碟。
- **升級流程**：講者把新版升級提示詞放上 GitHub repo（`Gem2Skill`），把網址貼給任何 Agent → Agent 掃雲端硬碟找出 Gems 列表 → 選編號 → Agent 給出能力加值選單（A 確定性詞庫演算法＋驗證器／B 支援單字清單自動生圖／C 直接產出單一 HTML 互動闖關題卡）→ 打包成技能。**前提：要先裝 Google 雲端硬碟電腦版，Agent 才抓得到。** 本集用 Gemini 3.7 Flash 在 AntiGravity 裡跑。
- **實測案例**：把「偵錯密碼（英文）」Gem 升級成 `English Error Cipher` 技能，能依國中七年級 A1 程度隨機出五題，並把五關合併成單一 HTML 網頁（圖片版走生圖、也可用 Emoji 版），最後用 **Cloudflare** 免費發布成公開網址。
- **注意**：需要生圖的技能只能在**原生支援生成圖片**的 Agent（AntiGravity、ChatGPT）裡跑。
- **技能怎麼叫**：打斜線列出全部技能（**裝完要重開 Agent 才看得到**）、或直接描述需求讓 Agent 自動呼叫。設定 → 客製化可以看到所有已安裝技能與 MCP（講者已裝 17 個技能＋Padlet MCP），Global 代表全域技能。
- **分享方式**：技能做成公開 GitHub repo，任何 Agent 讀網址就能安裝；換 Agent、換電腦都能裝回來。
- **PadletAutoBoard 示範**：給主題或教材，Agent 自動上網找資料並建好整面 Padlet。**前三個區段固定**：參考資料、投票、留言板；**第四個區段起**依內容決定區段數放主題內容；**最後留五個備用區段**，之後可以再用一句話把新內容（影片連結、GitHub repo、互動網頁）塞進指定備用區段。完成後直接給 Padlet QR Code。這一連串（上網搜尋＋連接 Padlet）正是 Gem 做不到的事。
