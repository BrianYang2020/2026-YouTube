## 2. 影片描述（≤300 字）

Claude Code 有個出來一陣子、但很少人知道的功能——Remote Control。打開它，你就能用手機、網頁版 Claude、或任何一台筆電，連回家裡那台電腦，繼續做同一個專案。

三個你會帶走的重點：
・兩層開關：先在 Settings 打開「Enable Remote Control by Default」，再在每個 Session 上打開 Remote Control（藍色代表已開啟）
・任何裝置都同步：手機 App、網頁版 Claude、另一台電腦，只要登入同一帳號、選到 Remote Control 的對話，看到的都是同一個對話，而且實際運算都在你家那台主機上跑
・檔案怎麼拿：讀寫的都是主機的檔案，所以把專案放在雲端硬碟，成果（HTML／PPT）在任何地方都能取用

唯一前提：家裡那台電腦不能關機。出門只要帶輕薄筆電，甚至借別人的電腦登入就行。

覺得有用記得訂閱、按讚、分享。留言告訴我：你會用哪個裝置遠端工作？
