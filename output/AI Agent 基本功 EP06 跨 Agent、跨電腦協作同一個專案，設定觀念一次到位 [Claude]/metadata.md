## 2. 影片描述（≤300 字）

「我有好幾個 Agent、好幾台電腦，怎麼一起做同一個專案？」這集一次把觀念拆解清楚。

三個你會帶走的重點：
・用雲端硬碟「應用程式」（不是瀏覽器版）把專案建在雲端，任何電腦、任何 Agent 都能讀寫同一個專案資料夾
・用 chezmoi 把你的技能與全域設定在多台電腦之間同步——chezmoi add 存起來、另一台 chezmoi update 就跟上
・三個核心技能：專案初始化（寫 agents.md 藍圖）、開工（載入上次進度）、收工（更新 GitHub／Obsidian／藍圖），再用 handoff.md 讓別的 Agent 或別台電腦無縫接手

搭配 Obsidian 當第二大腦、用另一個 Agent 互相審核，就能真正做到跨 Agent、跨電腦協作。三個技能已放說明欄，直接拿去用。

覺得有用記得訂閱、按讚、分享。留言告訴我：你目前用幾個 Agent、幾台電腦？
