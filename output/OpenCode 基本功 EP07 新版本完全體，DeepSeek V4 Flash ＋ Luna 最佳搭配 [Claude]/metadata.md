## 7. 內容備註（給日後剪同系列參考）

- **重要前提**：舊版 OpenCode 不會自動升級成新版，要重新到官網下載（搜尋 OpenCode Desktop Download）。
- **Go 方案**：每月 10 美金 → 60 美金用量；再切成每週 30 美金、五小時滾動額度。
- **兩個新模型**：
  - **DeepSeek V4 Flash 重新訓練版（0731）**：版本名不變但重訓過，變得非常聰明；純文字、看不到圖；100 萬上下文；一次呼叫約 0.0006–0.003 美金。需要打開「啟用部署在中國的模型」開關，走陸版伺服器（對來源有疑慮就別用）。
  - **GPT 5.6 Luna**：視覺模型，可讀文字／圖片／PDF；100 萬上下文；一次呼叫約 0.01–0.02 美金；同價位區間 CP 值第一。
  - 兩者都標 **2X Usage** ＝ 折扣拿不到、額度算兩倍消耗，實際各約 30 美金額度（**沿用 EP06 的教訓：2X 一律解讀為雙倍消耗，不是贈送**）。
- **核心觀念「用時間換智力」**：思考強度（reasoning effort）開高 → 便宜模型的智力分數逼近頂級模型。實測 Max 時 DeepSeek V4 Flash 與 GPT 5.6 Luna 都是 52 分，X-High 49、High 46；對照 Opus 5 為 60–61、Opus 4.8 Max 57、GPT 5.6 SOL Max 58–59。SOL 與 Luna 成本差 30 倍。太簡單的問題反而不該開高，也不需要開 Agent。
- **兩個免費技能**（都在說明欄放 GitHub repo）：
  - 免費看圖：申請 **Groq** 免費 API Key（Google 帳號註冊，權限選永不過期），塞進技能包；DeepSeek 需要讀圖時呼叫 Groq Vision 讀完再把內容送回。實測讀 114 年會考數學第 5 題的幾何圖形，頂點、角度、線段全部描述正確。
  - 免費生圖：打免費生圖網站生成後下載，再用思源黑體把繁體中文壓上去。缺點是慢、畫質輸 Nano Banana、且**認 IP**——教師研習場合整間教室同一個 Wi-Fi 會被擋。
  - 講者自己其實是接 OpenAI Image 2 的 API Key（一張約 0.3 元，儲值 20 美金約可畫 2000 張）。
- **破除誤會**：OpenCode 不弱。它能在同一個對話裡切換各家模型（GPT 做完馬上換 Opus 審查，上下文接得住），也能接本地端模型；Codex 只能用 GPT、Claude Code 只能用 Claude。可搭配 Zen 方案用頂級模型。
- **立場說明**：這個系列刻意以免費／低價方案為主軸，所以有些做法會比較麻煩，是取捨不是能力問題。
- **順帶提到**：MiMo V2.5 也幾乎免費且是視覺模型，但講者偏好 Luna；Kimi K3 太貴；預告之後可能出 Hermes 的教學，基本功系列差不多發完，接下來轉教學應用。
