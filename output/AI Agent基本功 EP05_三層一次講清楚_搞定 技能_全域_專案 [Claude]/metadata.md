## 2. 影片描述（≤300 字）

技能、全域、專案——AI Agent 的三層架構，這一集一次講清楚。

▸ 技能＝一份使用說明書：把你電腦能做的事（內部程式＋外部工具）組合成工作流，寫成 Markdown 文件。所有 Agent 通用，但「你長出來的技能才是你的技能」——別人的技能是在他的環境建置的，拿來要先改成適合你的工作流。
▸ 全域設定＝每次對話都載入的使用習慣。本集送兩個福利：「用語音回答我」（做完事用 Edge TTS 串流唸結論，不用盯螢幕）與「語音輸入文字正規化」（依上下文自動修錯字，全語音輸入不用改字，幾乎不耗 Token）。
▸ 專案＝大型複合技能。以台灣本土語（台語）教材專案示範專案思維：不上傳 1GB 檔案，而是請 Agent 把整套工作流寫成 GitHub repo 使用說明書，任何人的 Agent 讀完就能在自己電腦重現整個專案。

為什麼技能放第五集？因為你要先裝好 EP03 的內部程式、連好 EP04 的外部工具，做技能才不會卡。

福利檔案都在 Padlet，連結放說明欄。訂閱頻道，一起把 AI 用在教學上。
