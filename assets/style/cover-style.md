# YouTube 封面風格指南

> 此檔是頻道封面的唯一視覺基準。所有 `cover-image` Skill 呼叫的 prompt 都依此撰寫。
> 制定日期：2026-10-10。原作者（三師爸）的舊版風格存於 `docs/reference/`，**不要參考**。

## 頻道定位
**「把 AI 變成省時間的工具」**：每支影片承諾一個看得見的結果（省幾小時、抓出幾個錯、幾分鐘做完）。
封面的任務就是把這個「結果」講清楚，讓人在手機縮圖上一眼看懂。

---

## 一、三系列配色（一張封面只用一個強調色）

| 系列 | 角色 | 內容範圍 | 強調色 | 系列標籤文字 |
|------|------|----------|--------|--------------|
| **AI 自動化** | 主軸，最常出 | n8n、AI Agent、Claude Code／Codex 工作流、技能開發、RAG | 萊姆綠 `#C6FF3D` | `AI 自動化` |
| **AI × 金融** | 招牌，差異化 | 保險建議書／Excel 規格驗證、金融數據分析、波動度 | 金色 `#F5B700` | `AI × 金融` |
| **AI 辦公** | 引流，觸及廣 | 履歷、會議紀錄、講義、Email、日常辦公 | 亮橘 `#FF8A3D` | `AI 辦公` |

**判斷規則**：依「觀眾得到的結果」分系列，不是依用了哪個工具。
- 「用 n8n 自動寄報表」→ AI 自動化
- 「用 Claude 驗保單建議書」→ AI × 金融（雖然用 Claude，結果是金融）
- 「用 ChatGPT 改履歷」→ AI 辦公
- 跨系列時選「觀眾最在意的那個結果」，**不做雙色封面**

## 二、共用色票

| 用途 | Hex | 說明 |
|------|-----|------|
| 底色 | `#14161A` | 炭黑。**不用純黑**：人物穿深藍 polo，純黑底會吃掉衣服輪廓 |
| 主標第一行 | `#FFFFFF` | 白色 |
| 主標第二行（結果數字） | 系列強調色 | 放大 1.3 倍 |
| 系列標籤 | 強調色底＋`#14161A` 字 | 實心色塊 |
| 人物輪廓光 | 系列強調色 | rim light 打在人物外緣，讓深藍衣服從底色分離 |
| 輔助線條／小圖示 | 系列強調色 40% 透明度 | 克制使用 |

## 三、構圖（16:9 長片）

```
┌──────────────────────────────┬───────────────┐
│ [系列標籤]                   │               │
│                              │               │
│                              │    人物       │
│  主標第一行（做什麼）        │  （右側約 1/3）│
│  主標第二行（結果數字）      │   系列色      │
│                              │   輪廓光      │
└──────────────────────────────┴───────────────┘
   ←——— 左 62% ———→              ←— 右 38% —→
```

- **系列標籤**：左上角，小實心色塊。
- **主標**：左下，**兩行、每行不超過 6 個中文字**。第一行白字寫「做什麼」，第二行強調色寫「結果數字」，字級放大。
  - 好例子：「報表自動跑／省 3 小時」「保單建議書／抓出 3 錯」「零經驗履歷／10 分鐘」
  - 結果要具體、有數字；不要寫「超好用」「必學」這種空泛詞
- **字體**：超粗黑體繁體中文（思源黑體 Heavy 等級），**無描邊、無漸層、無 3D**；底色夠暗，白字與強調色本身就夠對比。
- **人物**：右側，約佔畫面寬 1/3，半身，臉部中心在右半邊。可微微越過中線。
- **主題視覺**（選用）：只在標題無法單獨說清楚時加一個小圖示或介面截圖，放在主標上方空白處，不可蓋過主標。

### 明確不要
- FREE 徽章、右下標籤帶、手捧發光終端機、放射光、粒子、網格背景（舊風格元素）
- 超過一個強調色
- 主標超過兩行
- 純白底、自然風景、寫實生活感背景

## 四、構圖（9:16 短片封面）

```
┌───────────┐
│ [系列標籤]│
│ 主標第一行│  ← 上半部：文字
│ 結果數字  │
│           │
│   人物    │  ← 下半部：人物胸像
│           │
│ （留空）  │  ← 底部約 20% 留空，避開 Shorts 標題與按鈕
└───────────┘
```
- 主標可拆成三行，每行不超過 5 個字。
- 用 `--size 1024x1536`。

## 五、人物表情對照

依標題情緒選 `--edit` 的輸入照片（**每次都重新讀照片，不可沿用上一張封面**）：

| 標題類型 | 例子 | 用哪張照片 | `{EXPRESSION}` |
|----------|------|-----------|----------------|
| 結果型（預設） | 省 3 小時、10 分鐘做完 | `assets/persona/人物形象照.png` | 自信露齒微笑，看向鏡頭 |
| 踩雷／驚訝型 | 算錯了、99% 的人不知道 | `assets/persona/expressions/驚訝.png` | 張嘴驚訝 |
| 痛點型 | 還在手動貼報表？ | `assets/persona/expressions/瞇眼皺眉.png` | 皺眉困擾 |
| 小技巧型 | 一個設定、密技 | `assets/persona/expressions/眨眼.png` | 眨眼壞笑 |
| 嚴肅分析型 | 金融數據解讀 | `assets/persona/expressions/自然.png` | 沉穩自然 |

人物特徵（寫進 prompt）：亞洲男性、短黑髮旁分、**無眼鏡**、深藍色 polo 衫肩線白色條紋。
**嚴禁**：改變五官、髮型、服裝顏色，或替人物加上眼鏡。

## 六、Prompt 範本

```
YouTube 封面 16:9，極簡高對比風格。

背景：純色炭黑 #14161A，無放射光、無粒子、無網格、無漸層。

人物：畫面右側約 1/3 寬，放置這位男性（短黑髮、無眼鏡、深藍色 polo 衫肩線白色條紋），
半身，表情「{EXPRESSION}」，看向鏡頭。人物外緣有 {ACCENT_NAME} {ACCENT_HEX} 的輪廓光，
讓深藍衣服與背景分離。
※ 人物樣貌、五官、髮型、服裝全部延續輸入照片，不要更動，不要加眼鏡。

文字（繁體中文，超粗黑體，無描邊、無陰影、無 3D）：
- 左上角：實心 {ACCENT_HEX} 小色塊，內有炭黑色文字「{SERIES_LABEL}」
- 左下第一行：白色「{LINE_1}」
- 左下第二行：{ACCENT_HEX} 色「{LINE_2}」，字級比第一行大約 1.3 倍
文字只能出現以上三段，不要任何其他文字、標點、logo 或浮水印。

{OPTIONAL_TOPIC_VISUAL}

整體：留白充足、元素極少、手機縮圖也能一眼看清主標。
```

填空變數：

| 變數 | 說明 | 例子 |
|------|------|------|
| `{SERIES_LABEL}` | 系列標籤文字 | `AI 自動化` |
| `{ACCENT_NAME}` / `{ACCENT_HEX}` | 系列強調色 | `萊姆綠` / `#C6FF3D` |
| `{LINE_1}` | 做什麼，≤6 字 | `報表自動跑` |
| `{LINE_2}` | 結果數字，≤6 字 | `省 3 小時` |
| `{EXPRESSION}` | 依第五節 | `自信露齒微笑` |
| `{OPTIONAL_TOPIC_VISUAL}` | 通常留空；需要時寫「主標上方空白處放一個小小的 {圖示}，不可蓋過文字」 | `n8n 流程節點圖示` |

### 三系列直接可用的範例

- **AI 自動化**：`{SERIES_LABEL}=AI 自動化`、`萊姆綠 #C6FF3D`、`報表自動跑`／`省 3 小時`、自信露齒微笑
- **AI × 金融**：`{SERIES_LABEL}=AI × 金融`、`金色 #F5B700`、`保單建議書`／`抓出 3 錯`、張嘴驚訝（`expressions/驚訝.png`）
- **AI 辦公**：`{SERIES_LABEL}=AI 辦公`、`亮橘 #FF8A3D`、`零經驗履歷`／`10 分鐘`、自信露齒微笑

## 七、標準呼叫指令

```bash
# 長片
python skills/cover-image/draw.py "<填好的 prompt>" \
  --edit "assets/persona/人物形象照.png" \
  --size 1536x1024 --quality low \
  --name cover --outdir "output/<標題> [Claude]/"

# 短片直式
python skills/cover-image/draw.py "<填好的 prompt，改成 9:16 構圖>" \
  --edit "assets/persona/人物形象照.png" \
  --size 1024x1536 --quality low \
  --name cover --outdir "output/<標題> [Claude] (Short)/"
```

- quality 一律 **low**；要實體印刷才升 high。
- 換表情時把 `--edit` 換成第五節對應的照片。
- **生完必看**：用 Read 檢查封面文字有無錯字、多餘標點、是否長出眼鏡；有問題就重生，prompt 補一句明確禁止。
