# 人物形象照（封面用）

本資料夾存放**所有 YouTube 封面的人物基準**。照片屬個人隱私，**一律不進 git**（見 `.gitignore`；repo 是公開的）。
換電腦時要手動把照片複製過來，原始檔是 `人物特徵.zip`（RunComfy 產出的 15 張一致性人像）。

## 檔案配置
```
assets/persona/
├── 人物形象照.png        # 基準照：正面、露齒微笑、白底（原 #04）——封面預設用這張
├── expressions/          # 表情變化，主題需要別的情緒時改用
│   ├── 自然.png          # 中性表情（#02）
│   ├── 驚訝.png          # 張嘴驚訝（#03）→「算錯了」「踩雷」「沒想到」
│   ├── 微笑.png          # 同基準照（#04）
│   ├── 瞇眼皺眉.png      # 痛苦／困擾（#05）→ 痛點型標題
│   ├── 眨眼.png          # 眨眼壞笑（#06）→ 小技巧、密技
│   ├── 側臉.png          # 左側臉（#07）
│   └── 背面.png          # 後腦勺（#13）
├── poses/                # 全身姿勢
│   ├── 張開雙手_polo.png # #08
│   ├── 五面轉身.png      # 正／斜／側／背轉身參考表（#15）
│   └── 張開雙手_帽T.png  # 藍色帽 T ＋灰色棉褲（#16）
└── scenes/               # 場景照（海灘／熱帶舉杯／月夜／公園／雨天街道）
```

## 人物特徵（寫 prompt 時用）
- 亞洲男性、短黑髮旁分、無眼鏡
- 固定穿著：**深藍色 polo 衫、肩線白色條紋**（`poses/張開雙手_帽T.png` 是唯一的帽 T 版本）

## 使用規則
- 呼叫 `cover-image` 時帶 `--edit assets/persona/人物形象照.png`；要換表情就換成 `expressions/` 內的檔案。
- **每一次封面都重新讀基準照**，不可從上一張已生成的封面延續人物。
- 照片皆為白底、未去背；gpt-image-2 edit 模式可直接使用。若要做「真人去背貼合成」的封面，需另外去背。

## 為什麼用 `--edit` 而不是純文字描述？
gpt-image-2 在 edit 模式會延續輸入圖的人物五官、髮型、穿著。純文字 prompt 每次出來的臉都不一樣，沒辦法做頻道識別。
